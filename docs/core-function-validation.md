## 工程修复

真实模型测试脚本的观察器原先在每个agent/created中挂载persona-memory并隐藏继承工具，会干扰独立worker的工作预设。修复后先等待实例管理器完成角色恢复，通过其当前coordinator的taskIsolation查宿主登记身份；可信worker及保留角色的已撤销worker只记录观察，不改变预设、不附加人格工具、不重新限制工作工具。普通父会话的挂载和工具作用域保持。

识别使用当前实例的可信服务，既不相信模型自报角色或裸header/preset，也不额外import另一份模块注册表。测试观察器修复不改变人格自主派发、记忆取舍或生产预设。

`scripts/dsh-delegation-integration.mjs --with-real-observer` 可以在固定响应的真实SDK验证中挂载同一观察器。默认入口继续只用固定fixture，无真实模型凭据；不带新选项时保留原35项验证。新选项另核首次worker与恢复后已撤销worker均未被观察器覆挂。
