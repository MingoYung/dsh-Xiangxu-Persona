# 3D记忆关联图

适用于dsh-Xiangxu-Persona 0.14.0。入口是 **相续人格 → 记忆 → 3D记忆关联图**。这张图把已经保存的记忆、原始来源、人物和会话关系呈现出来，便于查找与理解；不是读取模型内部神经元，也不把布局位置、颜色或连线解释成情绪实测。

本页说明本版源码与操作契约。最终完整隔离回归1507/1507通过；深浅主题和窄屏分别检查，普通desktop正常重启后已在实际设置页打开正式原件的局部图，观察到35节点／31关联并完成三维拖动。验收范围和限制见[0.14.0机器回执](verification/0.14.0-memory-graph.json)，不把历史QQ或模型实测算入本功能。

## 先看局部，再从具体经历展开

默认“共同记忆”只读取共同人格的派生条目和已保存关系，**不是整库，也不会自动加载全部聊天原文或归档**。可以按人物或未确认归属范围查看，也可输入线索缩小当前有界资料里的候选；图的筛选不等于已搜索所有历史。

想从一次真实交流开始，可点“从近期经历选一条”。近期选择器每页12条，支持翻页；只有你明确打开选择器才读取这一页，选择具体条目后再请求其局部图。记忆列表、关联检索和短期／长期／归档时间线也提供“在3D图中查看”入口，带上当前条目的完整复合身份。

明确选择原件后，后端按实际来源收据定位对应文件或归档分片，只在读取预算内加入同范围、同人物的原件；不会遍历其它归档来拼一张全库图。来自同一真实会话的原件可以通过会话节点连在一起，这表示共同来源，不证明它们在意义或感情上相似。未确认归属又没有选定原件时，界面会提示先选择具体经历，不能把空画布解释成没有记忆。

## 怎样操作

| 操作 | 效果 |
|---|---|
| 拖动3D视图 | 旋转查看真实三维坐标的透视投影 |
| 切换平面视图 | 用二维布局查看同一批节点和关系，拖动平移 |
| 放大／缩小、复位视角 | 调整当前视图，不改资料、关系或重要度 |
| 点击节点 | 查看摘要、实际关联及可查依据；也能从下方节点列表选择 |
| 查看完整记忆与来源 | 明确读取选中记录的详情，继续使用原有分页；图里的短预览不冒充完整原文 |
| 更换范围或具体起点 | 重新读取该范围内的有界局部，旧查询结果不能混入新图 |

图获得焦点后可滚轮缩放，Esc退出图形交互；节点列表和按钮可通过键盘操作。界面继承DSH主题，选中节点与邻接关系有可见状态，不要求靠颜色猜测。

实例切换时立即停止旧图、取消旧页面读取结果的接纳并清掉旧详情；详情固定在发起读取时的实例，不把旧人格的节点改投到新人格。隐藏时停止待绘制任务，离页时释放交互、观察器和画布引用，不把图留作后台持续动画。

## 节点和线各代表什么

| 节点 | 实际依据 | 展开方式 |
|---|---|---|
| 记忆／经历记录`record` | 当前保留的普通记忆、编码、深刻经历、人格条目、关系事件或明确选中的交流原件 | 使用复合`recordKey`打开同一条详情 |
| 来源`source` | 条目已保存的`srcRefs`和实际来源收据 | 查看来源身份与读取状态，不假称原文已经读过 |
| 人物`person` | 已登记人物和条目明确保存的`aboutPersonIds` | 表示资料提到了此人，不计算亲密度或替人格认人 |
| 会话`session` | 原件或来源引用的实际`sourceSessionId` | 表示来自同一会话，不当成语义或情绪关联 |

连线只依据已经保存的字段：`srcRefs`来源、`relatedMemoryIds`显式关联、`expandIds`编码展开、`supersedesIds`／`replacementIds`替代关系、`aboutPersonIds`涉及人物，以及真实会话来源。选中节点可查线的类型与依据。没有明确依据时允许孤立节点，不按文字相似度补线；编号存在歧义、目标未读或范围外时不猜测连接。

记录节点保留`[recordType,scope,personId,id]`复合身份，不因Alice和Bob使用相同编号就串在一起。来源角色与实际发言者仍沿原记录保存；关系归属不等于这句话一定是该人物说的。已撤销的原件、派生资料与注释不会借图或旧备份重新出现。

## 预算限制视图，不删除记忆

| 技术范围 | 默认或硬上限 |
|---|---|
| 显示节点／边 | 默认80／160，硬上限120／200 |
| 单次图请求打开文件／读取字节 | 最多8个文件、累计4 MiB |
| 元数据、派生文档、选中归档分片 | 分别最多2 MiB、每份512 KiB、每份1 MiB；归档目录另受256 KiB上限 |
| 投影遍历记录／来源收据索引 | 最多2048条／4096条 |
| 图响应JSON | 最多114688字节 |
| 实际画布像素 | 每边最多2048像素，总面积最多2097152像素；高分屏或极大容器会降低有效像素密度，保留逻辑坐标和点击命中 |

文件在读取前检查大小，再进行有界读取。这个接口不调用`_allMemory`把全库扫入内存后才截节点；明确选中的原件文件超预算时会说明未读，不偷偷越界。JSON文档在文件字节帽内解码，再按条目遍历上限投影，不把条目上限说成每次仅从磁盘读取这些条目的字节。

`coverage`报告实际读过和跳过的文件、原因、局部候选、已展示数量、未解析联系及范围；`readBudget`报告真实读取与遍历量。`total:null`与`entireStoreRead:false`明确表示不知道整库总图，而不是伪造精确全库数量。`catalogueComplete`只针对选定派生文档范围，不能解释为全部原文历史已经读取。

超限、省略或找不到节点只影响本次视图。程序不为让图更完整而删原件、不裁剪人格记忆，也不把未展示内容标成遗忘。需要更多上下文时，从具体记录、原有列表或详情继续查。

## 本地绘制与人格边界

渲染器随插件本地打包，使用Canvas2D绘制真实`x/y/z`坐标的三维透视；不依赖CDN、WebGL或额外图服务。只在交互、布局或主题等实际变化时绘制，采用有限布局，不安装持续动画循环。平面视图是同一资料的另一种布局。

查看、旋转、缩放、选择节点和读取详情均为只读浏览，不触发模型、回忆、整理、学习或人格更新，也不记录“用户点过所以更重要”。是否回忆、如何理解、记什么和怎样成长仍由人格自主决定。图不是操纵人格的控制面板。

先前[开源复用与二维图建议](open-source-reuse-and-memory-visualization.md)保留研究历史；本版选择本地轻量三维渲染与严格有界真实投影，没有迁移人格记忆后端。实际测试和正式加载以本轮回执为准，旧版QQ、模型或界面通过数不算本功能验收。
