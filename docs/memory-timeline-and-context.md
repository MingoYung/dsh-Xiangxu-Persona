# 时间线记忆与每轮人格背景

适用于dsh-Xiangxu-Persona 0.13.0。唯一字段与错误语义见[persona-schema第26节](plan/persona/persona-schema.md#0130-memory-timeline-contract)；日常操作见[使用说明](user-guide.md)。

## 交流保存一次，依次转层

每条实际交流使用同一格式，保存谁说的、原话、稳定编号、发生时间、初次记录时间与来源。短期默认最近3天，并受整个实例10万字符的近期容量约束；超过时间或容量就完整转入长期。长期活动正文默认100万字符，超过后把最旧的完整记录转入归档。转存不调用模型，不重新概括，也不要求人格再维护第二份长期日记。

例如，一条10月1日的交流从短期转入长期，之后又进入归档，它的编号、原话、说话者和来源仍是同一份。搜索或按编号展开仍能回查。三天决定存放层，不意味着三天后忘记，也不是三天必须成长、睡觉或整理一次。短期／长期／归档与整理用的临时过程工作区不同。

默认容量按Unicode字符计算，汉字、英文字符与完整Unicode码点分别计数，真实磁盘另按UTF-8字节、JSON结构、索引、WAL和副本统计。100万只约束活动长期的原文与统一注释，不包含全部人格、关系或深刻参考；后者仍受业务文档与实例物理容量保护。

## 统一格式保留经历，也容纳理解

| 内容 | 用途 |
|---|---|
| 标题与稳定编号 | 快速定位同一件交流和后续补充；标题可留空 |
| 发生时间与首次记录时间 | 分清事情何时发生、何时被记录；不把整理日期当经历日期 |
| 原始交流 | 保存实际正文、角色、人物与来源，是回查权威 |
| 前因、经过、结果与细节 | 人格需要时补充自己的经历说明，不强制每条写成文章 |
| 当时感受 | 保存人格自己形成的描述；未知时留空 |
| 现在的理解 | 可继续改变，不倒改过去原话 |
| 索引编码与关联记忆 | 与已有检索、编码和来源回查连接 |

这些注释由人格在自主整理中决定是否补充、修改或清空。程序不会为了填表编造经过，也不会规定应该高兴、受伤、治愈或原谅。清空注释保留原始交流；想明确遗忘原件时使用独立遗忘操作。

程序会记录注释实际依赖了哪些来源。例如A记录里对B事情的理解引用了B，之后明确遗忘B时，会清掉A中依赖B的注释，保留A无关的原话。恢复旧备份也要先应用现行遗忘，不能让旧注释把已经忘掉的内容带回来。来源记录有技术上限，超量会明确拒绝，不悄悄截掉来源。

## 查看和清理

在“记忆 → 短期、长期与归档”选择查看范围、填写查找线索并翻页。页面分别显示各层条数与字符；详情先给原始交流，再显示非空注释和来源。归档不等于已删除，某页末尾不等于整个库没有其它内容。普通对话的近期组装不读取全部长期／归档正文；你明确浏览或搜索某层时，当前实现会先扫描所选本地文件，再分页返回结果。分页控制显示和模型输入量，不代表大归档的磁盘读取也只花一页。

归档达到实例物理容量或磁盘安全边界时，程序保留已有资料并明确报告新副本无法保存，不自动删最旧归档。你可先备份、增加技术容量，或在归档中选择具体原件执行“明确遗忘这条归档…”。遗忘会按原依赖规则同时撤销受影响记忆，不是只删一个冷文件。没有默认全清或按情绪／重要度自动删除。

归档和活动层位于同一记忆库，不是独立备份。全部受管层进入文本备份／恢复／校验范围，但外部作品、供应商副本与宿主原件按各自实际范围处理。转层不丢内容不等于无限硬盘或硬件损坏后保证恢复；无法安全保存的新内容会明确报告缺口。

已有记忆库只迁移仍在的原件。旧版本已经裁剪、删除或没保存过的原话不能凭空补回来；有旧概括不等于全部原文已经恢复。这次保真是保证现存记录在转层中完整保留。

## 每次对话先带上必要背景

每次人格请求都先由程序加载当前身份核心（含当前自我描述）、人格anchor与axes、当前对象及关系概要、有效计划与休息事实，以及有界近期参考。这样，基础连续性不依赖模型这一轮是否想起调用工具。

详细性格条目、习惯、旧事和长篇背景仍按预算提供完整条目与来源，需要时继续展开。近期参考来自同一份原件，不再写一份短期摘要；超长正文显示真实Unicode片段范围，不冒称已读全文。已经作为本轮新来信提供的内容不会在近期段再重复一份。

动态参考默认总帽2970计数单位，近期局部帽默认600，仍在总额内；这不是整个DSH请求只有2970token。必要核心不无提示截断；总预算不足或必要资料加载失败时，明确提示本次无法加载人格并暂停生成，消息保留，恢复后再继续，不悄悄用普通AI回答。扩展材料的省略和原件可读性分别记录。

程序还会在实际模型请求前核对这一轮的system消息确实包含已准备的人格正文，防止其他插件后续覆盖提示导致人格丢失。核对只针对当前会话与这次请求，不阻断其他会话。未处理来信只登记待输入引用，不假称尚未读完的正文已经消费。新库可合法留空，已经保存过的身份档案若缺失则提示故障，不用空白人格替代。

加载参考不等于命令人格怎样想。是否联想某段往事、如何评价、怎样表达、是否形成深刻记忆、何时主动和睡眠，仍由人格决定。深刻参考不强制回忆或固定情绪。

按用户自行验证QQ的安排，QQ头像、资料和空间功能留待用户操作；本轮不运行真实模型或平台验收，也不要求新扫码。其它社交入口显示“未测试”，驱动支持、授权和实际连接仍分开显示。0.12.0及更早收发、扫码和模型结果保留历史范围，不作为本版已实测证明。
