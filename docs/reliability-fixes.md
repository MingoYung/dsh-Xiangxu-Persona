# 确认链、预算与 Windows 启动兼容补修

本批基于 CORE-F1 的工程问题修复，仍在 `0.14.0` 开发分支，没有另行发布市场版本。程序改动处理来源、交付、计数和进程启动，不规定人格该回复、记住、成长或采取什么行动。

| 范围 | 当前行为 | 验证边界 |
| --- | --- | --- |
| 唤醒与待答确认 | 接收唤醒摘要只确认交接；原待答保持。实际可见交付才能结算相应来信。 | 包含冷恢复、分片累计、迟到来信、沉默和未知平台回执。 |
| 同会话旧问题 | 可选 `replyPlan.pendingEventIds` 有实际消费者；完整原件已呈现、目标一致、真实交付后结算。 | 未读猜测编号、其他人物和会话不代为清除；不追认历史问题已经得到语义回答。 |
| 结构化 QQ | 原话、图片等派生资料分开保存，完整呈现判定复用已注册账号、会话和真实发送者范围。 | 有文字说明和无文字附件、完整与截短资料均有测试；没有新增正式 QQ 收发实测。 |
| 交付事实 | `persona_introspect section:state` 查看有限的呈现、输出和任务依赖事实，环境里只有短摘要。 | `streamObservedAt` 只说明该准入回合出现请求流，不证明供应商逐字收到原文或人格语义读懂；后来有输出、任务完成不代表旧问题已答。 |
| 预算预检 | 保存预算前用实际计数器对完整拼接材料测量，给出当前缺口及有界建议；应用建议需明确操作。 | 当前路由和已保存资料的检查，不担保未来成长、其他关系或供应商精确计费，不自动抬高完整请求硬顶。 |
| 整理恢复 | 最小封装装不下时保留原 run、页、偏移、候选和实际预算需求。 | 调整后继续原批；没有需求证据的旧 run 保持未知，不能伪造一个需求数字。 |
| 相对时间 | 可选 `nextCheckAfterMs`、`replyAfterMs`、`wakeAfterMs` 按实际提交时钟一次转换。 | 幂等重放不重新起算；不添加默认延迟、最短间隔、固定作息或必须行动。 |
| 旧任务公开视图 | 完整旧结果可追加 `final-report.txt`，默认读取公开文本，原封装和编号保持。 | 4 MiB 为投影处理上限。过大、损坏或容量不足仅使该项公开报告不可用，正常目录仍可浏览；原资料保留显式读取和下载。 |
| Windows PowerShell | 精确匹配的内置 ACL runner 通过子进程入口进入 Node 模式、创建隐藏 console，再执行原 runner。 | 原 ACL、受限 token、Windows Job、取消和控制字段继续生效；未改宿主 ASAR 或全局环境。 |

交付事实最多保留 256 条呈现、64 条输出、262,144 字节，不存原话。超限后明确报告诊断历史不完整，不因此删除人格记忆。任务关联查询也使用有界窗口并显示截断，事实服务不可用不会阻断正常聊天。

本批没有自动清理 CORE-F1 旧待答。没有被人格明确选中的旧问题，仍需要人格根据真实材料判断是否已经处理；补修不会替它下判断，也不保证它一定不会重新派任务。

## 本批验证

- 完整单元回归 **1,582/1,582**，无失败、取消或跳过。最后收窄请求流事实的措辞后，受影响的确认链与预算专项 **21/21** 继续通过。
- 新隔离 home 中真实 DSH SDK 的固定响应 provider 验证 **29/29** 检查通过，包含原生预设、工具执行、睡眠、唤醒、整理、冷恢复。固定响应验证不代表真实 LLM 的自然选择。
- 实际 Windows 原生组件三项通过：PowerShell 7.4.22 真正执行，中文输出和 UTF-8 文件保真，工作区外写拒绝、只读写拒绝、原环境值恢复。详见 [Windows 兼容说明](windows-powershell-compat.md)；组件证据与完整应用联验分开报告。
- 补充真实 DSH SDK shell 联验 **8/8 适用检查通过**：本地固定 provider 两次派发、一次实际 `pwsh` 工具、一次原生子进程，原 `workspace-write` 沙箱下命令、中文 stdout 和文件字节均成功，宿主正常退出。实际调用未请求 FD3，因此 FD3 在这一项是未覆盖，不把透传单测冒充原生回环。首次 overlay 漏声明 shell 依赖未进入工具和 provider，修正测试器后成功；两次测试进程均已收尾。
- 实际浏览器加载产品 UI，并连接真实管理接口与隔离运行时：必要材料 6,236、原预算 2,970，明确应用建议后预算 7,424、完整请求上限仍 32,768，显示可完整载入。模型没有生成入口，未接社交账号。
- UI 构建、JavaScript 语法、核心独立性、导出路径和打包清单通过。新增启动入口及技术事实模块实际进入包。

本批新增真实模型调用 **0**。没有在正式人格或社交账号上重放测试，没有部署或发布。本批工程通过不替代修复后的人格自主行为实测。CORE-F1 原失败证据仍保留，既往真实调用用量没有重算为本批零费用。
