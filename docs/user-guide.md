# 相续人格使用说明

适用于0.10.1的初始化、日常相处、可选检索与平台入口。相续是一位可以保留经历、形成持续自我描述的AI伙伴。可以从一句话开始，身份资料和可选功能以后再逐步确定。

## 开始相处

在DSH对话中选择“相续人格”预设即可开始。首次打开管理页时，可以选择设置初始资料，或点“以后再说”直接聊天；跳过不会删除已有资料，也不会阻止人格运行。此提示确认后不会反复要求你填写。

“了解相续 → 自我档案”提供三种方式：一起确定、由相续选择、暂不设置。一起确定时，先填写名字和你想表达的初始想法即可；称呼、性别表达、设定或外观年龄、生日与背景可在“更多身份资料”中补充，也都可以留空。

用户提供的初始想法和人格当前采用的自我描述分别保存。保存初始资料不会调用模型，也不会自动覆盖当前自我描述；是否接受、怎样理解自己、以后是否调整，由人格在相处中决定。改变初始化方式不会悄悄清空已保存的初始想法。

## 名字、年龄、形象与声音

当前自我资料、随经历形成的身份基调、形象档案和声音选择各有自己的用途。“自我档案”提供后几项的入口，不复制一份相互漂移的外貌或声音资料。

设定年龄、外观年龄、设定生日和实际相处时间分别看待。自我档案的首次保存时间只说明这份资料何时建立，不是人格的生日或诞生时间。头像、音色和年龄数字都不会自动决定性格、性别或成熟程度。

当前资料与有限旧版本可以在面板中查看。初始资料与当前描述分别以最多2400个Unicode字符保存，自我档案总容量64KiB，历史最多8个版本。内容超限会明确提示，不把这类容量当成人格成长指标。

## 新窗口与认识彼此

继续使用同一人格实例时，新开聊天窗口不等于重新创建人格。不同实例分别保存自己的资料。换平台、昵称或群聊环境时，可以提醒相续你希望被怎样称呼；称呼与账号是认识你的线索，不是身份认证，也不保证一定认对人。

不需要先完成个人问卷。可以直接聊事情，也可以慢慢互相介绍。是否询问称呼、继续追问或谈论自己，由人格结合实际交流决定。

## 记住、想起与检索

接收记录、当前回忆和长期记忆整理是不同过程。某次没有提起旧事，不代表历史已经被删除。尚未检索、检索未找到、记忆库为空和读取失败也不是同一种状态。

记什么、怎样理解和何时回忆，由相续决定。你可以在“记忆”查看已保留内容，在理解有误时直接纠正，或明确选择遗忘。遗忘与恢复的实际范围，以操作说明和回执为准。

## 聊天节奏

“相处 → 交流节奏”可以选择“自然短聊”（默认）、“按内容决定”或“完整展开”。这是表达偏好参考，不是字数、条数或频率的硬限制；需要解释复杂事情时仍可完整展开。

日常交流可以分次表达，但不保证每次发多条。是否继续、补充几句，由相续结合情境决定；不按标点自动切句，不用随机延时制造正在输入的假象，也不按消息数量强制成长。每次补充可能增加一次模型调用。

各渠道的发送方式与技术限制可能不同。已发送、排队和结果未知分别记录，不因某条未完成就假称整段已送达。使用时以当前渠道的实际能力和回执为准。

## 主动联系与休息

“允许主动找我聊天”表示允许相续自主选择联系时机，不保证每天或每隔多久主动一次。关闭后仍可接收你的来信；已经发出的消息不会撤回。

休息期间来信会保留。人格可以选择按时间、整理完成或等你叫醒；“现在叫醒”结束这次休息，让相续看到保留的来信。这可能调用模型，醒来后是否及如何回应仍由相续决定。

## 模型与可选能力

模型和思考强度会影响等待时间、用量与复杂判断，相关后台整理也可能沿用对应会话的选择。思考强度与感情深度没有直接对应关系，也不保证越高越自然。计费按当前模型服务和实际用量计算。

声音、图片、视频和平台连接均可按需使用。图片或视频服务可能另行收费；保存服务配置不等于开始生成，生成完成也不等于已经发给对方。

在“连接”选择QQ、微信后，按实际驱动扫码或配置兼容桥。支持范围、你的许可和当前可用状态分别查看；接通账号不等于拥有平台全部功能。当前官方QQ为Bot接入，微信官方接入为私聊；普通微信群、朋友圈或实时通话不能仅靠扫码获得。兼容桥也以实际驱动能力为准。

## 人格管理：切换、归档与清除

在“设置 → 人格管理”分别查看当前人格、其它人格和已归档资料。切换只改变使用哪套人格，不合并、覆盖或删除原资料；有正在执行的工作时，后端会提示先处理当前工作。

选择“新建人格”只需填写名称，明确“创建并使用”后，后台会建立新的独立资料目录并加载。成功后可以继续设置初始资料，也可以直接聊天；不会复制旧人格或旧会话的经历。需要自己指定绝对路径时，再使用“使用其他记忆库”高级入口。登记达到技术容量上限时会显示实际提示，不自动删除旧人格腾位置。

“归档保留”停止使用这个人格并保留资料，之后可明确“恢复并使用”。归档不是独立备份，不会删除记忆、作品、任务原件，也不会退出共享平台账号。归档、清除中、清除未完成或已清除的人格不能从顶部选择框直接使用；恢复操作在“人格管理”里明确完成。

“清除文本资料…”先读取后端实际范围、文件数与大小。请核对范围和不会清除的项目，完整输入预览指定的人格名称，再点击“确认清除人格文本资料”才会提交。预览五分钟内有效；过期或资料变化时需要重新预览。停止实例时产生的新收据也可能使本次预览失效，此时保持停用、尚未删除文件，请重新核对范围。取消、普通切换和归档都不会触发清除；如果只是暂时不用，可以选择“先归档保留”。系统不会背地备份后删除，也不会默认清除。

本轮清除的是已登记实例目录内的受管人格文本资料，包括相关记忆、关系、自我档案、暂存及运行记录等，以实际预览为准。DSH旧会话日志、其它实例、目录外作品二进制、独立任务原件、共享平台账号与凭据、外部备份不在清除范围。遇到未知文件会阻断清除并保留，不把整个目录当作可随意删除的资产。

清除完成后，旧实例保留状态标记，不能再次加载或重用同一个旧目录；需要继续相处时，请用新的独立目录创建实例。旧DSH会话日志仍然保留，但不会自动作为新人格的记忆接入。若清除未完成，界面显示“清除未完成”，保持不可加载；必须重新预览剩余范围、再次输入名称并明确确认后才继续，不自动重试删除。

## 容量、备份与排查

记忆有存储与上下文容量限制，不承诺永久保存全部聊天原文。可查看容量并按备份功能实际范围另存重要资料。文本备份不包含外部图片、视频、平台凭据或供应商保存的副本；用于生成的材料会交给你所选择的模型服务处理。

如果相续认错人、记错事或表达让你不舒服，可以直接指出具体内容。若反复声称刚认识你、把未检索说成完全没有记忆，或报出与档案不一致的资料，可记录使用的人格实例、模型、原话与时间，再在“设置 → 数据维护与诊断”查看实际状态，以便区分表达问题与技术故障。

这份说明可从“相处”或“设置”的“使用说明”入口回看，也可在“自我档案”中打开。查看说明不会启动模型、登录账号或执行管理操作；整份操作手册不会被作为人格规则逐轮注入。

## 按需要开通检索、B站与更多QQ能力

“记忆 → 查找关联记忆”可以用原话、近似描述或已知线索查找。默认文字和已有关系即可工作；“可选语义服务”需要你自备真实向量接口。保存并开启后，再点“建立一批索引”，只提交本批资料；查询文字也可能交给该服务处理并收费。索引只存在有容量限制的运行缓存中，重启或过期后可能需要重新建立，原始记忆不会因此被删掉。面板显示的“本次分页结束”不代表全库已缓存。

“当前有效”依据资料已有的有效区间；“已明确结束的旧理解”需要明确的结束时间。“指定时间有效”只查仍保留的内容，不是恢复到过去的整个记忆库。资料没有时间区间时不会被程序编造一个。检索记录只说明提供过什么候选或参考，是否真的想起、怎样理解仍由相续决定。

QQ丰富消息依赖实际OneBot桥。收到图片不代表已经看懂；模型支持视觉且附件保存成功才可附图。听语音需要在QQ桥配置中明确开启“入站语音转写”，DSH已有可用识别服务、桥也返回受支持音频；未识别会如实显示，不猜用户说了什么。语音转写与转发里的第三方内容保留各自来源，不冒充你键入的原话。

“连接 → B站”由你扫码、检查实际账号、保存需要的能力许可，再启用。默认没有操作许可；视频资料／字幕／评论／故事板各有实际覆盖，采样图片不等于完整看过视频。发表评论、回复和私信需要相应许可；分享只是给指定UID发视频链接。平台回执确认接收不等于别人已读或评论公开可见。结果未知时先查同一收据，不换编号重复发送。字幕会检查可核对的视频与轨来源，但来源字段通过不代表内容一定对应；相续仍需结合实际材料判断，程序不会替它删改或纠正字幕。

“连接 → QQ动态扩展”和“创作 → 可选翻唱服务”需要你自备兼容本插件协议的服务。动态不是普通QQ桥保证的功能；翻唱也不是选择一个TTS音色即可实现。导入真实音频、提交任务、查询结果和发送音频是分开的步骤，配置保存不会自动付费生成。音频库可保存每份16MiB的受支持容器，但本插件当前QQ OneBot11语音发送上限为8MiB，格式和实际可发仍取决于桥与平台；能导入不等于能发出。只想普通聊天可以全部不开通。

可选平台或服务初始化失败时，会显示各自诊断，不因此停止已正常加载的人格核心；该项能力仍不可用，不能越过错误继续操作。B站若遇到其它进程仍持有写锁，或遗留锁无法确认安全，先查看平台诊断并核实运行中的DSH进程，不要清空账号或人格来排查。只会在技术核验确认原写者已退出时安全恢复遗留锁；锁恢复不等于账号已经在线。

支持、授权、连接和送达是不同状态；这些接口不授予任意操作桌面客户端的权限，也不改变相续的自主判断。真实平台与供应商验收范围见[0.10.0 接入与检索说明](integrations-and-retrieval.md)；手机个人应用与Telegram仍留后续接口。

## 翻页、扫码恢复与上下文用量

记忆、认识的人和关联候选列表的上、下方都能回首页、上一页或下一页，每页12条。关联检索一次最多展示前100候选，找不到时可以换线索或范围，不代表其他记忆不存在。资料变化使翻页位置失效时，点“回到第一页重新读取”；切换人格后旧页面的迟到响应不会当作新人格资料。

B站二维码页面刷新后，可明确恢复本轮有效二维码，不需要反复申请新任务；四项权限和确认框使用同一组中文名称。已启用并保存凭据的账号启动时会核实一次，失败后不反复重试，也不会因此把整个人格停用。

“动态预算2970”不是一次聊天只能有2970个token。它约束程序提供的动态参考，默认可能按UTF8字节估计；聊天记录、系统指引、工具和宿主摘要另占输入。短期过程默认20万字符是存储目标，不是每轮都送给模型。本轮仅去除能够确认的同源旧系统快照投影重复，保留必要对话；不能据此保证每次用量或费用下降。实际范围与验收见[0.10.1 界面、检索与上下文验收](ui-retrieval-context-validation.md)。
